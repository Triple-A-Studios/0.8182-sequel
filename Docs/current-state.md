#### Pass 2 — UI foundation (draft detail)
Inputs received: **Baloo 2** and **Nunito** fonts, and the studio logo (`Art/Textures/UI/Tex_Logo.png`). Icons are placeholders until each screen's pass (list in gap analysis §9).
- **Fonts:** import into `Assets/_Project/Art/Fonts`, generate UITK font assets, check the glyphs the mockup uses (×, ·, ‹ ›). Fallback if a glyph is missing: image icon, not a second font.
- **`Theme.uss`:** the 13 palette tokens as USS variables, type scale classes (min 24px at reference size), and the component classes — chunky chip, primary/secondary/danger button, tab bar, popup card, back header, pip row, progress bar, slider, toggle, checkbox, segmented control. One file every UXML includes. Replaces the per-screen colours in `MainMenu.uss` and the HUD USS files.
- **Components:** reusable UXML templates (or small custom `VisualElement`s if templates prove too clumsy) for chip, buttons, tabs, popup, back header. Lip is a duplicate backing element (no `box-shadow` in USS). Press state keeps the shipped behaviour (**translate down by the lip height**, not the spec's 0.97 scale — that was a developer-caught on-device fix); one shared press manipulator replaces the per-script pointer-event code.
- **Background:** pick one approach for the vertical gradient + diagonal stripes (baked texture vs `generateVisualContent`) and apply it to a shared background element.
- **Screen router + popup layer:** a small stack (Show, Back, ShowPopup/Close) that the menu, leaderboard, settings, profile, shop and credits all use. Back buttons all return one level.
- **Safe-area helper:** one shared helper extracted from `MainMenuController` (24px base + `Screen.safeArea` insets), used by every screen.
- **Panel settings:** keep the single shared `FuelGaugePanelSettings.asset` (2400x1080, Match 0.5); rename it if a rename is safe for the GUID references, otherwise leave it and note it.
- **Proof:** a component gallery UXML/scene that shows every component and state at 2400x1080, kept as a dev reference. Does not touch gameplay screens (those start in Pass 3).
- **Done when:** fonts render in the Editor Game view (Android/WebGL font check happens in Pass 8 but a one-off WebGL spot check of the font is cheap and worth doing here), the gallery matches the mockup chips/buttons/popups, and nothing in the existing menu or HUD broke.

### Decisions (developer, 2026-10-07)
1. **Pause button (Pass 4):** visible but inert (toast); popup + countdown verified in the gallery only. No `timeScale` pause in this milestone.
2. **Cause and stats (Pass 5):** real `RunEndCause` plumbing in; stat chips and NEW BEST are static placeholders.
3. **Leaderboard data (Pass 6):** WEEKLY tab = real Top-10 from the existing daily board (mislabelled until #28); ALL-TIME = static sample data.
4. **Attempt-confirm memory (Pass 3):** "Don't ask again today" is in-session only.
5. **Game Over MAIN MENU (Pass 5):** stub toast. Real return-to-menu belongs to the Daily play structure milestone; reloading Bootstrap would re-run `BootstrapLoader` and risk duplicating leaderboard / UGS init. BANK IT, PRACTICE, LEADERBOARD and SHARE are stub toasts too; only RETRY (scene reload) is real.
6. **Settings joystick preview (Pass 6a):** follows the controls (ring scales with size, sits on the chosen side, handle travel follows sensitivity, snaps back). No drag-to-set-side.
7. **Display name (Pass 6c):** works in-session only (pencil, dice re-roll, confirm; the menu chip follows). Not persisted, not sent to UGS. Length cap is one constant, **16** (the mockup note said 14 with no recorded reason; developer chose 16, 2026-10-12).
8. **Screen-shake range (Pass 6a):** 0-150% per the S06 caption (the mockup fill implies 0-200); the pause popup slider follows the same constant.
9. **Past-week buttons (Pass 6b):** built with enabled / disabled / FINAL states, disabled in play until backlog #28; the gallery steps through four static sample weeks.

10. **Credits data (Pass 7a):** placeholders in one `CreditsContent` block for the developer to fill (name, handles, itch.io, email, support URL, thanks, attributions); the version line is real (`Application.version`), no invented build number.
11. **Rotate gate (Pass 7b):** loading screen only, as the S01 note. Rotating mid-session on web is carried to Pass 8 / the Pause milestone (the game cannot pause yet).
12. **Coins (Pass 7a):** coins are never purchasable with real money, so the coin chip's `+` button is removed; tapping the chip opens the Shop.
13. **Loading time (Pass 7b):** the loading screen stays at least 1.5 s (one constant); the bar still shows real progress.
14. **Touch size (Pass 8a):** tappable things are at least **80 reference px** (about 4.7 mm on a 6.4 inch phone, where 1 reference px is about 0.06 mm); the hit area may be larger than the visual.
