- **Working tree:** clean. `Data/Plugins/lib_burst_generated.wasm` is rewritten by every WebGL build; `git checkout` restores it.
- **Before you test:** reload the open scene after script changes before entering Play Mode. Editor is Unity 6000.6.3f1 (the active build target is WebGL; switching re-imports). All UI scripts use `PanelRenderer`, not `UIDocument`. The saved Sound setting persists between runs, so a silent Editor usually means Sound is 0. Haptics only vibrate on an Android player (`Haptics.Requested` shows them in the Editor); screen shake and joystick settings apply from the next shake / touch. Focus-loss auto-pause is off in the Editor unless `Auto Pause In Editor` is ticked on the `GameManager`; `Is Practice Run` there flips a run to practice (set it before Play). The leaderboard needs a linked Unity Cloud project and the `weekly_scores` / `alltime_scores` boards ([leaderboard.md](technical-design/leaderboard.md)). Tools > Daily Play > Reset Today's Attempts And Practice Time restores the day's counters for testing. A WebGL Build And Run uses a new localhost port per build, which looks like a new anonymous player each time (dev-only). An Android build uses the custom main manifest in `Assets/Plugins/Android/` (re-copy Unity's template and re-add VIBRATE + INTERNET when the editor version changes). The dev scenes in `Scenes/Dev` (`UIGallery`, `MenuScreensGallery`, `HudGallery`, `GameOverGallery`, `LaunchFlowGallery`) are not in Build Settings; their hotkeys are listed in `ui.md`.
