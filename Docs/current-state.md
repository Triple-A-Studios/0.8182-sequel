# Current State

## Snapshot
- **Last landed:** Milestone "Pause, settings & audio" (Alpha) — **complete** (7 passes in 10 steps, 2026-10-17 to 2026-10-24, branch `milestone/pause-settings-audio`). Pause is real (a `Paused` state in `GameManager` that owns `Time.timeScale`, a 3-2-1 resume, RESTART RUN, a leave-run confirm for competitive runs, auto-pause on focus loss, a portrait rotate overlay), every setting is persisted in PlayerPrefs and applied in play (sound, screen shake, haptics, joystick side / size / sensitivity, invert steering), the game has sound effects (no music, by design: a pooled `AudioManager` with priority, voice stealing and ducking, generated stand-in clips) and Android haptics (light / medium / heavy / crash-rhythm profiles as ms + amplitude arrays). Verified in the Editor, on an Android phone (native build, custom manifest) and in WebGL on the phone's browser. Frozen pass table with commits: [progress.md](progress.md#milestone-pause-settings--audio--completed). Systems: [game-flow.md](technical-design/game-flow.md), [settings.md](technical-design/settings.md), [audio.md](technical-design/audio.md), [haptics.md](technical-design/haptics.md).
- **Now:** between milestones. The remaining Alpha milestones are unscoped: **3D art pass**, **Daily play structure** (it also needs the weekly + all-time leaderboard rework, backlog #28), **Player profile & run stats**. Next step: the developer picks the next milestone; scoping it starts with a check of the open backlog and a pass breakdown.

- **Open items leaving the milestone:** the open backlog in [progress.md](progress.md) (#19-#21 spawning, #23 slow-mo crash, #24 movement juice, #28 weekly + all-time leaderboard rework). The "Placeholder data registry" in `ui.md` is the checklist for the milestones that make each stand-in real (now including the stand-in sound effects, the default haptic patterns, the QUIT TO MENU toast and the practice-run checkbox); `CreditsContent.cs` still holds a placeholder name / links / thanks for the developer to fill. Real audio clips are dropped in by name (see audio.md).
- **Uncommitted in the working tree (the developer's, not part of any pass):** `ProjectSettings/ProjectSettings.asset` (the version bump) and `Data/Plugins/lib_burst_generated.wasm` (rewritten by every WebGL build; `git checkout` restores it).
- **Before you test:** reload the open scene after script changes before entering Play Mode. Editor is Unity 6000.6.3f1 (the active build target is WebGL; switching re-imports). All UI scripts use `PanelRenderer`, not `UIDocument`. The saved Sound setting persists between runs, so a silent Editor usually means Sound is 0. Haptics only vibrate on an Android player (`Haptics.Requested` shows them in the Editor); screen shake and joystick settings apply from the next shake / touch. Focus-loss auto-pause is off in the Editor unless `Auto Pause In Editor` is ticked on the `GameManager`; `Is Practice Run` there flips a run to practice (set it before Play). The leaderboard needs a linked Unity Cloud project and the `daily_scores` board (High to Low, Best Score, daily reset 00:00 UTC) until backlog #28 replaces it. A WebGL Build And Run uses a new localhost port per build, which looks like a new anonymous player each time (dev-only). An Android build uses the custom main manifest in `Assets/Plugins/Android/` (re-copy Unity's template and re-add VIBRATE + INTERNET when the editor version changes). The dev scenes in `Scenes/Dev` (`UIGallery`, `MenuScreensGallery`, `HudGallery`, `GameOverGallery`, `LaunchFlowGallery`) are not in Build Settings; their hotkeys are listed in `ui.md`.
