An Android build uses the custom main manifest in `Assets/Plugins/Android/` (re-copy Unity's template and re-add VIBRATE + INTERNET when the editor version changes). The dev scenes in `Scenes/Dev` (`UIGallery`, `MenuScreensGallery`, `HudGallery`, `GameOverGallery`, `LaunchFlowGallery`) are not in Build Settings; their hotkeys are listed in `ui.md`.
